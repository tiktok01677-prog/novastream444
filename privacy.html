ASPIRECOMPASS · VERSION 1.0

Privacy policy

Effective date: October 4, 2026

Calculations and practice

This version processes mathematical expressions and practice answers in your browser or Android WebView. It does not send those expressions or answers to a server. It includes no user accounts, ads, analytics SDKs or AI services.

Local device storage

The app stores calculation history, bookmarks, practice progress, theme and angle settings locally. These are not synchronized across devices. Use Saved & history to clear calculation history or reset practice progress. Clearing browser or app storage removes all local settings and saved data. Offline caches contain app files and can be removed by clearing site storage.

Hosting

If this app is hosted on GitHub Pages, GitHub receives requests needed to deliver the app and may log IP addresses for security. Refer to GitHub’s privacy statement for hosting practices. Mathematical input is not included in those requests.

External links and clipboard

Opening an external link takes you to that provider’s website, which has its own privacy practices. Copying a result writes text to the device clipboard only when you select Copy.

Support and updates

Contact the repository owner using the issue tracker of the GitHub repository hosting this app. If accounts, analytics, ads or other SDKs are added later, the publisher must update this policy and the corresponding store declarations. This policy describes the supplied web app; the publisher must also describe any data processing added by their Android wrapper.
