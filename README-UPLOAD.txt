HISAAB — GITHUB PAGES READY

Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Important: upload the assets folder as well as index.html.

Then GitHub:
Settings -> Pages -> Build and deployment -> Deploy from a branch
Branch: main
Folder: /(root)
Save

Open the GitHub Pages URL shown by GitHub, not the github.com repository/file URL.

This version intentionally uses assets/ instead of _next/ so GitHub Pages/Jekyll cannot drop the JavaScript and CSS folder.
No npm install and no build command are required for this package.
